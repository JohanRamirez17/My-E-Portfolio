# Johan Ramirez — E-Portfolio

A responsive, single-page personal portfolio for Johan Ramirez, built with plain HTML, CSS, and a small JavaScript enhancement. No build tools or dependencies are required.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. GitHub Pages will publish the site and show its URL in the Pages settings.

## Personal details

The portfolio uses information supplied in Johan’s resume. Update `index.html` if any contact details, school names, dates, or other information should be corrected or changed before sharing publicly.
